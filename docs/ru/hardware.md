# Железо и зафиксированные результаты

Референсный хост: Ryzen 7 5700X (8 ядер / 16 логических CPU), macOS Tahoe 26.0.1, build 25A362, x86_64. AMDVM использует существующую конфигурацию Hackintosh без дополнительного патча XNU для AMDVM или собственной сборки ядра. Проверен только этот хост. Нужны SVM, NPT и их разрешение в прошивке.

Зафиксированы SYSCFG `0x740000`, TOP_MEM `0xd0000000`, TOP_MEM2 `0x830000000`; 8 variable MTRR (4 активных), 48 бит физического адреса. Это описание данного хоста, а не универсальные значения для записи на другой машине.

## Матрица

| Сценарий | Результат и границы |
| --- | --- |
| CPUID/SVM MSR query всех 16 CPU хоста | PASS |
| No-RUN подготовка RAM/NPT, state roundtrip и destroy | PASS |
| Фиксированные HLT и CPUID → OUT → HLT ROM | PASS |
| Alpine 3.24 / 1 vCPU / 512 МиБ, 1 ГиБ, 2 ГиБ | записаны интерактивные загрузки |
| Alpine / 4 ГиБ, 2 настроенных vCPU, до AP-фикса | загрузилась; CPU1 не прошёл alive handshake, online только CPU0 |
| Конечная SMP ROM / 2 vCPU / 4 ГиБ | исполнялись оба vCPU; stop и host rendezvous PASS |
| Alpine / 2 ядра / 256 МиБ после AP-фикса | online=0-1, nproc=2, конечная нагрузка на каждом ядре PASS |
| Та же загрузка с диска под TCG, 2 ядра / 256 МиБ | оба ядра online; контрольный эксперимент |
| Остановка исправленного SMP SVM, poweroff и quit | paused за 1,626 мс; SVM MSR всех 16 CPU восстановлены, карантин нулевой |
| 4 гостевых ядра / 8 ГиБ, другие ОС, migration/hotplug | не подтверждено |

Последний SMP-тест использовал `pc`, один socket, два core, один thread на core, VirtIO block/network/GPU, экран 1280×800 и SLIRP NAT. Ядро гостя: `6.18.55-0-virt`; в более ранней сессии — `6.18.52-0-virt`. Дополнительные аргументы гостевого ядра не вводились. См. [evidence](../../evidence/reference-2026-10-14/README.md).

Публичный frontend принимает 1–2 vCPU и 256 МиБ–4 ГиБ. Это политика допуска, не проверка всех сочетаний. Внутренние 64 слота ABI не доказывают работу 64-vCPU гостя. Общий frontend отличается от аппаратно проверенного бинарника публичным RUN-профилем и допуском ресурсов; его сборка/офлайн-проверки отражены отдельно в [MANIFEST.json](../../MANIFEST.json).

## Отчёты о проверках

Укажите модель CPU, плату/AGESA, RAM хоста, версию/build macOS, UUID и SHA-256 kext, commit и hash QEMU, команду запуска, версию гостя, выбранные ресурсы, реально online CPU гостя, первый отказ и результат stop/cleanup. Удалите пароли и приватные пути хоста перед публикацией логов.
